Detailed Description

A single boolean flag, armed via arm_next_poll() (typically from another thread) and both checked and disarmed – cheaply enough for the hottest of paths – via poll_armed().

It is the signaling building block of the Polled_shared_state pattern (see Polled_shared_state doc header), wherein one embeds a Poll_flag in each per-thread state of a Thread_local_state_registry; but it is usable stand-alone, wherever a thread must cheaply, opportunistically notice a rare request from another thread.

void flow::util::Poll_flag::arm_next_poll ( )
inline

From any thread: causes the next poll_armed() call to return true (once).

If already armed, it stays armed (this is not a counter).

If arming signals a change to some shared data (e.g., Polled_shared_state::while_locked()-guarded state), finish writing that data – and unlock – before calling this; the memory-ordering internals then guarantee the poll_armed() caller sees the writes.
