Detailed Description

template<typename T, typename Allocator>
template<typename U>
struct flow::util::Default_init_allocator< T, Allocator >::rebind< U >

Satisfies Allocator concept optional requirement for rebinding to another type U: the result is a Default_init_allocator adapting the adaptee allocator rebound to U.

Without this std::allocator_traits would use the adaptee's own rebind (if any; e.g., std::allocator in C++17), silently dropping the adaptor; and containers rebind routinely (e.g., vector to its own element type; list to its node type).
